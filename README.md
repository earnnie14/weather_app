# 🌤️ Weather App

A Flutter weather application that provides real-time weather information with a beautiful Glassmorphism UI.

## 📱 Features

- 🌡️ Current weather (temperature, humidity, wind, visibility)
- 📅 7-Day forecast
- 🔍 Search by city name
- 📍 Auto GPS location
- 🌅 Sunrise and Sunset times
- 🎨 Dynamic background color by weather

## 🛠️ Built With

- Flutter - UI Framework
- Dart - Programming Language
- OpenWeatherMap API - Weather Data
- Geolocator - GPS Location
- HTTP - API Requests

## 🚀 Getting Started

1. Clone the repo: git clone https://github.com/earnnie14/weather_app.git
2. Install dependencies: flutter pub get
3. Add API key in lib/config.dart
4. Run: flutter run
